\section*{Code and data availability}
The code is public: \url{https://github.com/phananh85327/LMSPS} holds the data pipeline and the
search, and \url{https://github.com/phananh85327/han-improve} the models and the evaluation. The
results come from commit \texttt{\val{repo-lmsps-commit}} of the first code base and commit
\texttt{\val{repo-han-commit}} of the second. The records of every run are stored with the two code
bases. In the first, the script \code{hgb/generate_data.bat} rebuilds the cleaned data from SNAP's
raw file (which we do not redistribute) and the script \code{paper/make_numbers.py} computes every
number, table and figure of the paper from those records.

\section*{Use of AI assistance}
We used an AI assistant, Claude (Anthropic). The manual path sets were designed with its assistance
from the principles in Section~\ref{sec:setup}, before any result was known. It reviewed the code,
suggested directions and fixed errors. It also helped write the script that computes the paper's
numbers, tables and figures from the run records. The author proposed the study, with its base
methods, dataset and reference papers, in a project proposal that planned to compare discovered and
hand-picked meta-paths in HAN and metapath2vec, with GAT as a reference. The author also wrote the
first versions of both code bases, adapting the original code of LMSPS and HAN to link prediction.
The author ran every experiment. The author reviewed all of this work and takes full responsibility
for the content.
